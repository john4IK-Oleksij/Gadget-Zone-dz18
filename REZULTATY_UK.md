## 1. Резюме Проєкту

У ході виконання завдання DZ-18 було реалізовано повноцінний E-Commerce інтернет-магазин:
1. **Асинхронний бекенд на FastAPI + SQLAlchemy 2.0 + MySQL 8**: реалізовано REST API, рольовий доступ (RBAC), чисту архітектуру (роутери, сервіси, моделі) та промисловий рівень безпеки.
2. **Фронтенд на чистому стеку (Vanilla HTML5 / CSS3 BEM / Vanilla JS)**: без використання Node.js runtime, сторонніх бібліотек чи фреймворків, із реактивним рендерингом нативних ES-модулів.
3. **Хмарна готовність (Railway Deployment)**: додано всі файли конфігурацій (`requirements.txt`, `Procfile`, `railway.json`), автопідключення до MySQL та постійних дисків для фотографій (Railway Volumes).

## 3. Результати Реалізації Фронтенду (12 Ітерацій)

Фронтенд розроблено строго поітераційно згідно специфікацій:

* **Ітерація 1 (Базова структура):** Каркас із 5 семантичних HTML-сторінок (`index`, `details`, `cart`, `login`, `admin`), підключення ES-модулів.
* **Ітерація 2 (Дизайн-система):** Фірмова палітра 60/30/10 (Cream, Dark Green, Green, Mustard Gold для дій, Burgundy для небезпеки) на базі методології BEM.
* **Ітерація 3 (Спільний Хедер):** Закріплена липка шапка (`header-sticky`) із тінню, бургер-меню для мобільних та непомітний індикатор стану бекенду (зелена/червона крапка з автопінгом).
* **Ітерація 4 (Каталог та Пагінація):** 
  * Серверна пагінація порціями по 8 товарів.
  * Плавний сповільнений скрол (750ms `easeInOutCubic`).
  * Керування з клавіатури стрілками ⬅️ / ➡️.
  * Захват рукою мишкою (`cursor: grab / grabbing`) та тач-свайпи для мобільних.
* **Ітерація 5 (Деталі товару):** Хлібні крихти, картка характеристик, лічильник з контролем складу, блокування покупки товарів із нульовим залишком або знятих із продажу.
* **Ітерація 6 & 7 (Аутентифікація та Безпека):**
  * Двотокенний захист JWT.
  * **Тихе автооновлення (Silent Refresh):** автоматичний запит на `/auth/refresh` при `401 Unauthorized` без викидання користувача.
  * **Таймаут бездіяльності (Inactivity Guard):** скидання сесії та редирект через 5 хвилин повної відсутності рухів миші, клавіш або скролу.
* **Ітерація 8 & 9 (Кошик та Mini-Cart):**
  * Повна синхронізація з бекендом.
  * Статус **«Знято з продажу» (`is_active = false`)**: затемнення картки, деактивація лічильника, активна кнопка видалення та перегляду деталей.
  * Спливаючий Mini-Cart у шапці (вимкнено на сторінці `cart.html`).
* **Ітерація 10 (Адмін-зона):** Авторизаційний захист, дашборд статистики, реєстр користувачів із порядковими номерами `#`, CRUD товарів із завантаженням фотографій та модальними попередженнями.
* **Ітерація 11 (Адаптивність):** Повна оптимізація під смартфони (до 400px) та планшети (767px), touch target від 44px на всіх інтерактивних зонах.
* **Ітерація 12 (Фінальна Верифікація):** 0 помилок у консолі браузера, всі флоу перевірено та схвалено.

## 4. Ключові Архітектурні та Інженерні Рішення

1. **E-Commerce Soft Delete:** Заборона фізичного Hard Delete у магазині для збереження фінансової історії та цілісності кошиків покупців.
2. **Чистота коду FastAPI:** Застосування стандарту PEP 593 (`Annotated[AsyncSession, Depends(get_db)]`) для повного усунення попереджень Ruff `B008` та відмова від «сліпих» `except Exception:` (Ruff `BLE001`).
3. **Виправлення Windows Async Event Loop:** Конфігурація `asyncio_default_test_loop_scope = "session"` у `pyproject.toml`, що усунуло системну помилку Windows `RuntimeError: Event loop is closed`.
4. **Універсальний API URL:** Автоматичне розпізнавання `http://127.0.0.1:8000` при локальній розробці та відносного шляху `""` при роботі у хмарі.
