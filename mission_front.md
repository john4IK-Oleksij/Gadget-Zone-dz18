# Gadget Zone — Frontend Architectural Specification & Mission (Production Blueprint)

> **Статус документа:** Золотий стандарт фронтенду (Production-Grade Frontend Reference Architecture).  
> **Призначення:** Вичерпна специфікація архітектури, дизайн-системи, компонентів, безпекових та UX-протоколів, а також поітераційний чеклист для розробки сучасного Vanilla JS фронтенду. Будь-який новий агент повинен використовувати цей документ як еталонний зразок.

---

## 1. Архітектурні Принципи та Технологічний Стек

* **Vanilla Web Standards Only:** Чистий HTML5, CSS3 (за методологією BEM), Vanilla JavaScript (стандартні ES Modules).
* **Жодних фреймворків чи бандлерів:** Без React, Vue, Angular, Node.js runtime, Webpack, Vite чи npm-залежностей на фронтенді.
* **Потік даних:**
  ```text
  HTML (Семантична розмітка)
         ↓
  Vanilla JS (ES Модулі)
         ↓
  Fetch API (Централізований apiRequest)
         ↓
  FastAPI Backend (JSON REST API)
         ↓
  Reactive DOM Rendering (Клієнтський рендеринг без перезавантаження)
  ```
* **Єдиний бекенд-адаптер (`front/js/api.js`):**
  Автоматичне визначення оточення (працює і локально, і в хмарі без зміни коду):
  ```javascript
  export const API_BASE_URL = (
      window.location.hostname === '127.0.0.1' && window.location.port === '5500'
  ) ? 'http://127.0.0.1:8000' : '';
  ```

## 2. Дизайн-система (Palette 60 / 30 / 10)

Суворе дотримання колірної гармонії:
* **60% — Cream (`#E9DCC0`):** Загальний фон сторінки, картки товарів, світлі підкладки, модальні вікна.
* **30% — Dark Green (`#0F2F24`) та Green (`#0A5A4A`):**
  * `Dark Green`: закріплений хедер, футер, навігація, заголовки `h1-h3`, основний текст, бейджі ролей.
  * `Green`: інформаційні банери, hover-ефекти, рамки активних елементів, успішні сповіщення.
* **10% — Mustard Gold (`#B8860B`):** **Виключно для цільових дій (CTA)** — кнопки «Add to Cart», ключові конверсійні кнопки. Заборонено фарбувати в золото другорядні елементи.
* **Акцент небезпеки — Burgundy (`#6B1F2B`):** Виключно для деструктивних дій (видалення товару, банери помилок, бейджі «Знято з продажу»).

## 3. Безпека, Авторизація та Сесії на Клієнті

### 3.1. Двотокенна модель та Тихе оновлення (Silent Refresh):
* Зберігання токенів у `localStorage` (`gadgetzone_token` та `gadgetzone_refresh_token`).
* Усі запити виконуються з заголовком `Authorization: Bearer <access_token>` та параметром `credentials: 'include'`.
* **Перехоплювач 401 (Auto Silent Refresh):** Якщо сервер повертає `401 Unauthorized`, `apiRequest` у фоні надсилає запит на `POST /auth/refresh`, оновлює пару токенів та автоматично повторює початковий запит. Активний користувач або адмін не відчуває переривання роботи.

### 3.2. Протокол Бездіяльності (Inactivity Guard — 5 хвилин):
* Модуль `front/js/inactivity.js` відстежує активність користувача: рухи миші (`mousemove`), кліки (`mousedown`), натискання клавіш (`keydown`), скрол (`scroll`) та тач-події (`touchstart`).
* Захист від надлишкового навантаження: фіксація активності тротлиться до 1 разу на 2 секунди.
* **Спрацьовування таймауту:** Якщо протягом **5 хвилин** не зафіксовано жодної взаємодії:
  1. Викликається `clearToken()`, видаляються всі JWT-токени.
  2. Очищається мітка останньої активності.
  3. Користувач автоматично перенаправляється на `index.html` як гість.
  4. Виводиться банер помилки: *"Session closed due to inactivity"*.

## 4. Специфікація Сторінок та UX-Інновацій

### 4.1. Спільний Хедер (`header.js`):
* **Липке позиціонування (Sticky Header):** Хедер закріплений зверху (`position: sticky; top: 0; z-index: 100`) з плавною тінлю `box-shadow: 0 2px 10px rgba(15, 47, 36, 0.25)`.
* **Індикатор здоров'я API (Health Check Dot):**
  * Непомітна 8-піксельна крапка поруч із логотипом.
  * Зелена (`#2ecc71`) — сервер доступний.
  * Червона (`#e74c3c`) з м'якою пульсацією — бекенд офлайн.
  * Пінгує `/db-test` кожні 20 секунд та слухає системні події `api-health-status`.
* **Рольовий вигляд:**
  * Гість: кнопки входу/реєстрації.
  * Клієнт: email, Cart (з лічильником бейджа), Logout.
  * Адмін: email, перемикач `Admin Panel`, Logout (**без кошика**).

### 4.2. Каталог та Пагінація (`index.html` + `products.js`):
* **Серверна пагінація:** Порції по 8 товарів на сторінку (`limit=8`, `skip=(page-1)*8`), синхронізація через URL-параметр `?page=X`.
* **Кінематографічний плавний скрол:** Функція `smoothScrollToTop(750)` з кубічною функцією плавності `easeInOutCubic` (м'який початок, прискорення, плавна зупинка).
* **Керування клавіатурою:** Стрілки ⬅️ `ArrowLeft` та ➡️ `ArrowRight` для перемикання сторінок (ігноруються, коли фокус у полі вводу).
* **Захват рукою та свайпи:**
  * Десктоп: жест перетягування мишкою (`cursor: grab / grabbing`). Протягування вліво ➔ наступна сторінка, вправо ➔ попередня. Клік по товару під час перетягування безпечно блокується.
  * Мобільні: горизонтальний тач-свайп пальцем (`touchstart` / `touchend`).

### 4.3. Кошик та Статуси Товарів (`cart.html` + `cart.js`):
* **`stock_quantity = 0` («Unavailable / Out of stock»):** Товар залишається в кошику, виводиться червоний напис `Unavailable (out of stock)`, замовлення блокується.
* **`is_active = false` («Знято з продажу / Discontinued»):**
  * Застосовується стиль `.cart-item--discontinued` (напівпрозорість `opacity: 0.65`, пунктирна рамка).
  * Червоний бейдж **«Знято з продажу»**.
  * Лічильник кількості деактивується.
  * Кнопка видалення `×` залишається активною. Посилання на деталі товару залишається клікабельним.
* **Mini-Cart (`mini-cart.js`):** Випадаючий дропдаун при наведенні/кліку на іконку кошика в шапці. Автоматично вимикається на сторінці `cart.html`, щоб не перекривати основний контент.

### 4.4. Адмін-панель (`admin.html` + `admin.js`):
* **Захист входу:** Негайна перевірка ролі; якщо сесія закінчилася — миттєвий редирект на `index.html` із банером помилки доступу.
* **Таблиця користувачів:** Відображення зручного порядкового номера `#` (1, 2, 3...) замість сирого DB ID, форматування дат.
* **Модальні вікна підтвердження:** Попередження перед зняттям товару з продажу.
* **Завантаження зображень:** Підтримка завантаження файлу з комп'ютера з автоматичним прев'ю та збереженням читабельного імені файлу для користувача.

### 4.5. Адаптивність та Мобільна ергономіка (`responsive.css`):
* Основні точки зламу: `767px` (планшети) та `400px` (смартфони).
* Мінімальний розмір інтерактивних елементів (touch target): **44 × 44 px**.
* На тач-пристроях іконки швидкої дії (Око, Кошик) постійно закріплені в правому нижньому кутку фотографії без потреби в hover.
